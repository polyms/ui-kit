## v2.0.0

Release after **1.0.5**. Steps `50` through `950` on primary, success, info, warning, and danger keep the same hues. Buttons, links, badges, and alerts already read those steps. This release removes the bare color names and moves gray chrome onto the neutral ramp. It also adds Chip, ChipInput, Toggle, and ToggleGroup, and shares one set of tokens for control corners, focus, and overlay panels.

### Removed color aliases

- **Breaking change:** The bare color tokens are removed. `--color-primary` used to point at step 700. `--color-success`, `--color-info`, `--color-danger`, and `--color-warning` used to point at step 500. Use that step directly in CSS.
- **Breaking change:** Tailwind color utilities with no step are removed. `bg-primary`, `text-primary`, `border-primary`, and `shadow-primary` become the `primary-700` utilities. The same names for success, info, danger, and warning become step 500, so `bg-success` becomes `bg-success-500`. An opacity suffix moves with the step: `bg-primary/10` becomes `bg-primary-700/10`, and `text-danger/70` becomes `text-danger-500/70`.
- A theme block copied from these docs sets the step tokens. See [Design Tokens](/design-tokens).

### Neutral gray ramp

Gray chrome uses **neutral**. `--color-neutral-50` through `--color-neutral-950` are the slate hue, and the `bg-neutral-*`, `text-neutral-*`, and `border-neutral-*` utilities follow that hue once the package styles are loaded.

- **Breaking change:** `--fg`, `--surface`, `--muted`, and `--line` read neutral steps. A custom value on `--color-slate-*` leaves body text, surfaces, and dividers unchanged. Set the matching neutral step.
- In your own chrome, use the same step on `neutral`. `bg-slate-100` becomes `bg-neutral-100`, `text-slate-500` becomes `text-neutral-500`, and `border-slate-300` becomes `border-neutral-300`.

See [Design System](/design-system) for the full ramp and [Dark mode](/docs/dark-mode) for these roles in both modes.

### New components

- **Chip** is a compact value such as a skill, category, or recipient. **ChipInput** collects several of those values in one field. See [Chip](/docs/chip).
- **Toggle** is a two-state button. **ToggleGroup** keeps a set of them in one shell and uses the same `size` and `rounded` steps as Field and Button. See [Toggle](/docs/toggle).

### Spinner color

- **Behavior change:** A spinner with no `color` uses `currentColor`, so it follows the surrounding text, including inside a button or on a dark surface. The track uses that color at 25% opacity. In 1.0.5 the defaults were `#181b1f` and `#AEB4BD`. Pass those values when a screen still needs them. See [Spinner](/docs/spinner).

### Shared control and overlay tokens

Buttons, fields, selects, toggles, and toolbars share one corner radius, focus ring, and press wash. Modal and offcanvas share one panel fill.

- Set `--control-radius`, `--control-ring`, `--control-ring-width`, and the `--control-*-tint` steps to change those controls together. `--control-ring` is the control color that switches under `.dark`. The shared ring is 3px wide.
- Set `--overlay-bg` to change the modal and offcanvas panel. It follows `--body` until you set it. `--dialog-radius`, `--sheet-radius`, `--popup-radius`, `--group-radius`, and `--popup-shadow` size the shells around them.

See [Design Tokens](/design-tokens).
