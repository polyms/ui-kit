## v1.1.0

<span className='badge badge-primary'>Latest</span>

Release after **1.0.5**. The numbered color steps (`50` through `950`) stay as they are. Buttons, links, badges, alerts, and the other components already read those steps.

- **Breaking change:** The bare color tokens are removed. `--color-primary` used to point at step 700. `--color-success`, `--color-info`, `--color-danger`, and `--color-warning` used to point at step 500. Use that step directly in CSS.
- **Breaking change:** Tailwind color utilities with no step are removed. `bg-primary`, `text-primary`, `border-primary`, and `shadow-primary` become the `primary-700` utilities. The same names for success, info, danger, and warning become step 500, so `bg-success` becomes `bg-success-500`. An opacity suffix moves with the step: `bg-primary/10` becomes `bg-primary-700/10`, and `text-danger/70` becomes `text-danger-500/70`.
- A theme block copied from these docs no longer includes a bare alias such as `--color-primary: var(--color-primary-700)`. Set the step tokens instead. See [Design Tokens](/design-tokens).
