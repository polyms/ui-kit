After you install **`@polyms/ui-kit`**, you can add a bundled **agent skill** so AI coding assistants — Cursor, Claude Code, and other tools that read `AGENTS.md` — compose UI the same way this library expects. Install it once in your repository instead of pasting conventions into every prompt. For the visual and composition rules the skill enforces, see [Design System](/design-system).

## What you get

The skill teaches your assistant how to work with UI Kit in common product tasks:

The installer writes the skill once, in `.agents/skills/ui-kit`. Codex reads that folder. Cursor, Claude Code, and Copilot follow symlinks to it:

- `.agents/skills/ui-kit` — the skill files (Codex)
- `.cursor/skills/ui-kit` — symlink for Cursor
- `.claude/skills/ui-kit` — symlink for Claude Code
- `.github/skills/ui-kit` — symlink for Copilot

## Install the skill

You need **`@polyms/ui-kit`** in the project first — see [Installation](/installation). From your repository root, run the bundled installer:

```bash
pnpm exec ui-kit-skill
```

```bash
npx ui-kit-skill
```

## Options

```bash
ui-kit-skill [options]
```

- **`--target <all|cursor|claude|codex|copilot|agents>`** — `all` writes `.agents/skills/ui-kit` and links Cursor, Claude Code, and Copilot. `cursor`, `claude`, or `copilot` writes `.agents` when that folder is missing, then links only that tool. `codex` and `agents` write the folder and skip the symlinks. Codex loads `.agents/skills/ui-kit` directly.
- **`--cwd <path>`** — repository root to install into (default: current directory).
- **`--force`** — overwrite an existing skill (useful after upgrading the package or re-syncing the team).
- **`--dry-run`** — show what would be written without changing files.
- **`-h`, `--help`** — show usage.

Install for a single tool:

```bash
ui-kit-skill --target cursor
```

Preview without writing:

```bash
ui-kit-skill --dry-run
```

## Keep it in sync

The skill ships with the package and updates when you upgrade **`@polyms/ui-kit`**. Re-run the installer after each upgrade. Add a script so everyone on the team syncs the same way:

```json
{
  "scripts": {
    "ui-kit:skill": "ui-kit-skill --force"
  }
}
```

```bash
pnpm ui-kit:skill
```

## Verify

Confirm the skill files and the tool links:

```bash
ls .agents/skills/ui-kit
ls -l .cursor/skills/ui-kit .claude/skills/ui-kit .github/skills/ui-kit
```

Then try a real prompt in your assistant — for example:

```text
Create a login form with Field, a primary submit Button, and inline validation errors.
```

The output should use `@polyms/ui-kit` imports and match the patterns in the [Design System](/design-system). If anything disagrees with your installed version, trust **`node_modules/@polyms/ui-kit/index.d.ts`**.

## Brand kit in your repo

To keep AI-generated UI on-brand, add a theme file (for example `src/styles/theme.css`) and a short **`BRAND.md`** in your app with accent colors, surfaces, and which components carry the brand. Full setup and examples: [Design System — Brand theming](/design-system#brand-theming).

Example prompt:

```text
Our BRAND.md is at ./BRAND.md. Update theme.css so the primary ramp matches our brand tokens.
```
