Display brief, non-blocking feedback messages to users about the outcome of an action or system event. Toasts appear temporarily and auto-dismiss, ensuring they don't interrupt the user's workflow.

## Usage

```tsx
import { Button, Toast } from '@polyms/ui-kit'

function App() {
  return (
    <Toast>
      {/* Your app content */}
      <Toast.Container />
    </Toast>
  )
}

function MyComponent() {
  const toastManager = Toast.useToastManager()

  const saveButton = (
    <Button
      onClick={() =>
        toastManager.add({
          title: 'Success!',
          description: 'Your changes have been saved.',
          type: 'success',
        })
      }
      variant='primary'
    >
      Save Changes
    </Button>
  )

  return saveButton
}
```

## Position

Set placement once on **`Toast.Container`** — it controls where the stacked toast viewport sits on screen. Default is **`bottom-right`**.

```tsx
import { Toast } from '@polyms/ui-kit'

const appShell = (
  <Toast>
    <main>{/* routes */}</main>
    <Toast.Container position='top-center' />
  </Toast>
)
```

## Types

Toasts support five types for different feedback contexts. Each type (except `actions`) displays a matching icon and color scheme.

### Success Toast

Used for confirming successful operations like saving data, completing uploads, or sending messages.

```tsx
toastManager.add({
  title: 'File uploaded',
  description: 'Your document is now available.',
  type: 'success',
})
```

### Info Toast

Neutral updates that are useful but not urgent — product news, tips, or status that is not a success or failure.

```tsx
toastManager.add({
  title: 'New update available',
  description: 'Version 2.0 is ready when you are.',
  type: 'info',
})
```

### Warning Toast

Alerts users to potential issues that require attention but aren't critical errors.

```tsx
toastManager.add({
  description: 'Your session will expire in 5 minutes.',
  type: 'warning',
})
```

### Danger Toast

Communicates errors or failed operations that need immediate user attention.

```tsx
toastManager.add({
  description: 'Failed to save changes. Please try again.',
  type: 'danger',
})
```

### Action Toast

Provides an actionable button for users to respond to the notification, such as undo operations.

```tsx
const id = toastManager.add({
  description: 'Message deleted',
  type: 'actions',
  actionProps: {
    children: 'Undo',
    onClick: () => {
      toastManager.close(id)
      // Undo logic here
    },
  },
})
```
