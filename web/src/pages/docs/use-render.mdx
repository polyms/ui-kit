**`useRender`** powers the **`render`** prop on **`Button`**, **`Field`**, **`Breadcrumb`**, **`Modal`**, and other components. Use it when the same styles must apply to a different element (router link, custom tag) without rebuilding the component.

## Typing

```tsx
import { mergeProps, useRender } from '@polyms/ui-kit'
import clsx from 'clsx'

type CardProps = useRender.ComponentProps<'div'>

export function Card({ className, render, ref, ...props }: CardProps) {
  return useRender({
    defaultTagName: 'div',
    ref,
    render,
    props: mergeProps<'div'>({ className: clsx('card', className) }, props),
  })
}
```

Prefer **`mergeProps`** over spreading when combining library defaults with consumer props so **`className`**, **`style`**, and event handlers merge safely. **`ref` is not merged by `mergeProps`** — use **`useRender`'s `ref`** option (a single ref or an array). Details: [mergeProps](/docs/merge-props).

## Button as anchor

```tsx
import { Button } from '@polyms/ui-kit'

const button = (
  <Button render={<a href='/settings' />} variant='primary'>
    Settings
  </Button>
)
```

## Breadcrumb item customization

```tsx
import { Breadcrumb } from '@polyms/ui-kit'

const breadcrumbItem = (
  <Breadcrumb.Item render={<span className='breadcrumb-item' />} active>
    Current page
  </Breadcrumb.Item>
)
```
