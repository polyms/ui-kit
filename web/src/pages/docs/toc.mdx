Anchor readers to the sections on the current page. **`Toc`** tracks which headings are in view and styles items for you — no manual scroll-spy wiring on each link.

## Usage

```tsx
import { Toc } from '@polyms/ui-kit'

const items = [
  { title: 'Overview', url: '#overview', depth: 2 },
  { title: 'Setup', url: '#setup', depth: 2 },
  { title: 'Tips', url: '#tips', depth: 3 },
]

const pageToc = (
  <Toc>
    <Toc.List>
      {items.map((item) => (
        <Toc.Item key={item.url} depth={item.depth} href={item.url}>
          {item.title}
        </Toc.Item>
      ))}
      <Toc.Indicator />
    </Toc.List>
  </Toc>
)
```

Give each heading on the page a matching **`id`**. Hash **`href`** values register with the root scroll spy; clicking an item smooth-scrolls to that heading.

## Behavior

### Scroll spy

`Toc` watches registered item fragments and applies **`is-visible`** / **`is-primary`** on the matching items. You do not need to call **`useVisibleHeadings`** for the compound tree.

When content scrolls inside an overflow container (not the window), pass that element’s ref as **`scrollRef`** on **`Toc`**:

```tsx
import { useRef } from 'react'
import { Toc } from '@polyms/ui-kit'

const Article = () => {
  const scrollRef = useRef<HTMLDivElement>(null)

  return (
    <div className='overflow-auto' ref={scrollRef}>
      {/* article headings… */}
      <Toc scrollRef={scrollRef}>{/* … */}</Toc>
    </div>
  )
}
```

Use **`useToc`** inside the tree if custom chrome needs the same state, or **`useVisibleHeadings(ids, { root })`** when you build a list outside **`Toc`** (pass **`root`** when the page scrolls in an overflow container).

### Range indicator

Render **`Toc.Indicator`** inside **`Toc.List`**. It spans from the first to the last **visible** item and hides when none are visible.

### Button items

Omit **`href`** to render a button — useful for a “back to top” control with **`scrollToTop`**.

### Accessibility

- Root defaults to **`aria-label="Table of contents"`** on a **`nav`**
- Items with **`href`** are real links; omit **`href`** for buttons
- Hash clicks call **`preventDefault`** and **`scrollToHeading`** unless your **`onClick`** already called **`preventDefault`**
