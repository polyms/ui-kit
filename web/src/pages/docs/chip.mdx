Chips represent compact values such as skills, categories, or recipients. Use **`Chip`** for a standalone value and **`ChipInput`** when people need to add, select, or remove multiple values.

## Chips

Chips have one compact size. They can show a leading icon or avatar, use a theme, display a selected state, and include a dismiss button.

```tsx
import { Chip } from '@polyms/ui-kit'

const chips = (
  <>
    <Chip>Default</Chip>
    <Chip variant='primary'>Primary</Chip>
    <Chip avatar={<img alt='' src='/avatar.png' />}>With avatar</Chip>
    <Chip onDismiss={() => {}}>Dismissible</Chip>
  </>
)
```

### Theme variants

Pass **`variant`** to set a chip's tone. Chips use a subtle background by default so a selected chip can use the solid tone.

```tsx
const themedChips = (
  <>
    <Chip variant='primary'>Primary</Chip>
    <Chip variant='success'>Success</Chip>
    <Chip variant='danger'>Danger</Chip>
    <Chip variant='warning'>Warning</Chip>
    <Chip variant='info'>Info</Chip>
  </>
)
```

### Active state

Set **`active`** to show the solid selected appearance. For a selectable standalone chip, provide **`onClick`** and control its active state from your app.

```tsx
const selectedChip = (
  <Chip active variant='primary'>
    Selected
  </Chip>
)
```

## Chip input

Use **`ChipInput`** for a field that manages multiple values. Press **Enter** or type a comma to add a value. Values are trimmed and duplicates are rejected by default.

```tsx
import { ChipInput } from '@polyms/ui-kit'

const skillsInput = (
  <>
    <label htmlFor='skills'>Skills</label>
    <ChipInput
      id='skills'
      label='Add a skill'
      defaultValue={['React', 'TypeScript']}
      variant='primary'
      placeholder='Add a skill…'
    />
  </>
)
```

Use **`value`** with **`onValueChange`** for controlled state, or **`defaultValue`** for an uncontrolled field. **`createOnBlur`** adds the remaining text when focus leaves the field; it defaults to `true`.

Pass **`rounded`** to give the shell the same corner radius as a textarea (`rounded-xl`, 12px). Chips inside the field stay pills.

### Empty state

An empty input is ready for the first value. Set **`defaultValue`** to `[]` or omit it.

### Disabled

Set **`disabled`** to prevent adding and removing values. Existing chips and dismiss buttons become unavailable.

## Keyboard behavior

`ChipInput` supports keyboard navigation and selection:

- In the empty input, **Backspace** or **Delete** selects and focuses the last chip. Press either key again to remove the selection.
- **←** at the start of the input focuses the last chip. **Shift+←** selects it.
- On a focused chip, **←** and **→** move between chips; **Shift+←/→** extends the selection. **Home** focuses the first chip and **End** returns to the input.
- **Backspace** or **Delete** removes selected chips. **Cmd/Ctrl+A** selects all chips, and **Escape** clears selection and returns focus to the input.
- Click selects one chip. **Cmd/Ctrl+click** toggles a chip, and **Shift+click** selects a range.

## Accessibility

Associate a visible **`<label>`** with the input by passing an **`id`** and matching it with **`htmlFor`**. Chips in `ChipInput` are keyboard-focusable, dismiss buttons have accessible names, and additions/removals are announced to assistive technology.
