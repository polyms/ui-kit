Class-based dark mode for **`@polyms/ui-kit`**. Add **`.dark`** to `<html>` (or any wrapper) and semantic utilities switch between light and dark palettes at runtime — no CSS rebuild.

Dark body background defaults to **`#2e3440`** (Nord Polar Night). Semantic tokens resolve at runtime when you toggle **`.dark`** — built-in components and utilities pick up the inverted palette automatically.

## Setup

Enable dark mode by adding the class to the document root (or a subtree):

```html
<html class="dark"></html>
```

Optional sync with system preference:

```tsx
const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches
document.documentElement.classList.toggle('dark', prefersDark)
```

`color-scheme` is set automatically (`light` on `:root`, `dark` on `.dark`) so native controls and scrollbars follow the theme.

## Tokens

Surface tokens set the page. Control and overlay tokens set corners, focus, press washes, and dialog chrome. The reference at the bottom lists each name. Only `--control-ring` changes under `.dark`. Override them anywhere in your app:

```css
.dark {
  --body: #1a1b26;
  --surface: #24283b;
  --surface-2: #1f2335;
  --input: #1f2335;
}
```

## Utilities

Short semantic classes for app shells and custom layout — prefer these over hardcoded gray/white when building theme-aware UI:

```tsx
const layout = (
  <div className='bg-body text-fg min-h-dvh'>
    <header className='border-line border-b bg-surface px-4 py-3'>
      <h1 className='font-semibold'>Dashboard</h1>
      <p className='text-muted text-sm'>Welcome back</p>
    </header>
    <main className='p-4'>
      <div className='rounded-lg border border-line bg-surface p-4'>
        <p className='text-fg'>Card content</p>
        <p className='text-muted text-sm'>Supporting detail</p>
      </div>
    </main>
  </div>
)
```

**`html`** and **`body`** use **`bg-body text-fg`** once library styles are loaded — toggling **`.dark`** on `<html>` updates the whole page background.

## Component colors

Dark mode preserves your brand ramps. Solid intent buttons keep their saturated brand fills with white text;
outlined buttons, selected tabs, and interactive rows use accent text with transparent tints.

Table stripes, active rows, and hover states resolve through semantic surfaces, so light text stays readable.
Popovers use the muted text token for descriptions. Spinners inherit the surrounding text color by default.

## Tailwind dark variant

After importing **`@polyms/ui-kit`** styles, use Tailwind **`dark:`** for one-off overrides in app-specific layout:

```tsx
const layout = <div className='border border-line bg-body text-fg dark:bg-surface'>…</div>
```

Works with responsive and state variants: **`md:dark:bg-surface`**, **`hover:dark:bg-surface`**, etc.
