A flexible form field wrapper that combines labels, inputs, descriptions, and validation feedback into a cohesive component. Use it to collect user input such as text, email, passwords, or search queries with proper accessibility and visual hierarchy.

## Usage

```tsx
import { Field } from '@polyms/ui-kit'

const field = (
  <Field required>
    <Field.Label>Let me know your email?</Field.Label>
    <Field.Control placeholder='tifa.lockhart@polyms.dev' />
    <Field.Description>We'll never share your email with anyone else.</Field.Description>
  </Field>
)
```

**`Field.Floating` is not a child of `Field`.** Do not nest them.

## Icons

Place `HugeiconsIcon` with `className='icon-start'` or `'icon-end'` as **siblings** of `Field.Control` inside the `Field` root (after `Field.Label` when the label is visible). See the default demo.

## Common mistakes

- Raw `<label>` + `<input>` instead of the compound tree
- `invalid` on `Field.Control` — put it on **`Field`** root
- Using `Field.Floating`'s `placeholder` prop as the HTML input placeholder
- Inventing `Field.Input` or importing `FieldFloating` separately
- Expecting `Field.Feedback` to take a `render` prop — pass the message as **`children`**

## Disabled and read-only

Pass **`disabled`** or **`readOnly`** on **`Field.Control`**. Disabled inputs block interaction and use reduced opacity; read-only inputs keep the value readable with a muted background and suppress hover border and focus ring styling.

## Invalid state

Pass **`invalid`** on **`Field`** to apply error styling (danger border, text, and focus ring). Add **`Field.Feedback`** for the validation message — it portals as a tooltip near the control and opens on focus-visible, hover, or click. Use **`defaultShowOnError`** to keep it visible while invalid. Pass **`floatingRoot`** with a DOM id when the feedback must portal into a specific container (for example a modal body) instead of `document.body`.

```tsx
import { Field } from '@polyms/ui-kit'

const emailField = (
  <Field invalid={hasError} required>
    <Field.Label>Email</Field.Label>
    <Field.Control value={email} onChange={onEmailChange} />
    <Field.Feedback defaultShowOnError>Enter a valid email address</Field.Feedback>
  </Field>
)
```

## Debounced onChange

Pass **`debounce`** (milliseconds) on **`Field.Control`** to delay **`onChange`** until typing pauses—useful for filtering or validation without work on every keystroke. Omit **`debounce`** or use **`0`** for synchronous **`onChange`** (native behavior).

```tsx
const field = (
  <Field>
    <Field.Label>Search</Field.Label>
    <Field.Control debounce={300} onChange={(e) => console.log(e.target.value)} />
  </Field>
)
```

## Floating label

**`Field.Floating`** bundles a floating-label input with optional helper text. Pass **`debounce`** when you want **`onChange`** to fire after a quiet period; omit it for updates on every change. Use **`placeholder`** for the description below the field, not the HTML placeholder (the input uses a blank placeholder so the label can animate).

```tsx
import { Field } from '@polyms/ui-kit'

const fieldFloating = (
  <Field.Floating
    label='Search'
    placeholder='Results update as you type'
    debounce={400}
    onChange={(e) => console.log(e.target.value)}
  />
)
```
