**`mergeProps`** combines multiple React prop objects when you wrap or compose elements. Import it from **`@polyms/core-ui`** with **`useRender`**.

## Usage

```tsx
import { mergeProps, useRender } from '@polyms/core-ui'
import clsx from 'clsx'

type CardProps = useRender.ComponentProps<'div'>

export function Card({ className, render, ref, ...props }: CardProps) {
  return useRender({
    defaultTagName: 'div',
    ref,
    render,
    props: mergeProps<'div'>({ className: clsx('card', className) }, props),
  })
}
```

## How merging works

- Most keys — rightmost object wins
- **`className`** — concatenated (rightmost first)
- **`style`** — shallow-merged (rightmost keys overwrite)
- **Event handlers** — all run (rightmost first)
- **`ref`** — **not** merged; only the rightmost `ref` is kept. Pass multiple refs through **`useRender({ ref: [internalRef, ref] })`** instead

## With the render callback

When **`render`** is a function, props are not auto-merged onto your element. Merge the callback props with your own:

```tsx
import { mergeProps } from '@polyms/core-ui'

const trigger = (
  <SomeTrigger
    render={(props, state) => (
      <button type='button' {...mergeProps<'button'>(props, { className: 'my-trigger' })}>
        {state.open ? 'Open' : 'Closed'}
      </button>
    )}
  />
)
```

See also [useRender](/docs/use-render) for polymorphic composition.
